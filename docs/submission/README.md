# Obliq submission package

This directory contains the judge-facing and operator-facing material for GitHub Issue #7. It documents the implemented product and recorded evidence; it does not itself qualify a network, send email, create a wallet, or move funds.

- [Project description](./PROJECT_DESCRIPTION.md)
- [Technical summary](./TECHNICAL_SUMMARY.md)
- [Three-minute demo script](./DEMO_SCRIPT.md)
- [Local demo runbook](./LOCAL_DEMO_RUNBOOK.md)
- [Submission checklist](./SUBMISSION_CHECKLIST.md)

Status claims use the repository vocabulary: `IMPLEMENTED`, `SEEDED`, `PLANNED`, `BLOCKED`, and `UNAVAILABLE`. `REGTEST VERIFIED` and `READY FOR FUNDED TEST` are explicit evidence scopes, not synonyms for production readiness.
