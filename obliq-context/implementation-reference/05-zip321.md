# ZIP-321 Payment Requests

ZIP-321 is the canonical Zcash payment-request URI standard for Obliq where compatible.

Use it for:
- destination
- exact amount
- shielded memo when permitted
- human-readable label/message only when those fields do not leak sensitive data in the chosen UX/transport context.

Obliq requirements:
- Validate generated payment requests.
- Use exact settlement amount.
- Use an opaque obligation reference in encrypted memo data for shielded recipients.
- Never place secrets or internal finance details into a URI that may be copied, logged, screenshotted or shared.
- QR rendering is a presentation layer over the canonical request, not a separate payment model.

Re-read ZIP-321 before implementation and write conformance tests for the subset Obliq uses.
