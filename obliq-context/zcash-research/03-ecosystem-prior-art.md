# Zcash Ecosystem Prior Art

This file is a duplication guard. A startup can compete with existing
products, but it needs a real wedge rather than a renamed clone.

## Zodl

Self-custodial flagship wallet focused on shielded ZEC. Features
publicized in 2026 include ZEC payments, shielding, encrypted shielded
notes, swaps/CrossPay, retail payment integrations, Tor-related privacy
features, and hardware-wallet work.

Implication: "Beautiful Zcash wallet" is not enough.

## Zingo

Existing Zcash wallet and developer ecosystem.

Implication: Generic wallet functionality is crowded.

## CipherPay

Non-custodial Zcash payment processor. Merchant supplies viewing
authority, receives checkout functionality and webhooks, and invoices
can use diversified addresses.

Implication: "Stripe for Zcash" already has credible prior art.

## ROZO Merchant POS

Attempted merchant POS flow focused on fast retail confirmation. The
public grant discussion exposed an important problem: mempool detection
is an early signal, not final settlement, and physical retail has strict
latency/risk constraints.

Implication: A POS startup needs a stronger risk and settlement model
than a QR demo.

## Myaza

Proposal around ZEC wallet/POS usage and local-fiat conversion in
Africa.

## Rvess Pay

Proposal for shielded ZEC deposits and mobile-money payouts in East
Africa, including reconciliation and TypeScript backend components.

Implication: "ZEC to African mobile money" is active territory. A new
startup needs differentiation beyond geography.

## Veridex

Proposal around passkey-authenticated shielded wallets and AI-agent
payments.

Implication: Passkeys + Zcash or "AI agent pays with ZEC" alone is not
novel enough.

## Paid Private File

Non-custodial private digital-file sale using shielded ZEC and Nym. Uses
view-only payment detection and diversified addresses.

Implication: Private digital commerce is feasible, but a single
paid-file marketplace is a narrow vertical.

## ZcashMe authentication

Hackathon project that turns a shielded transaction into a private
sign-in flow exposed to apps through familiar OIDC tooling.

Implication: "Login with Zcash" has meaningful prior art.

## ZEC-OS

Rich Zcash ecosystem interface with explorer, mempool/network data,
tools and applications.

Implication: A dashboard/explorer/toolbox should not be our startup
thesis.

## Current grant activity

Recent public grant activity includes wallet connectivity, atomic swaps,
payment receipts, state integrity, fiat ramps, payment rails/cards, sync
engines and other infrastructure.

Implication: Always check current grants and forum activity before
claiming a gap is untouched.
